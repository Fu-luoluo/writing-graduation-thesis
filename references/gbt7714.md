## 1. 引文标注体制

1. 采用**顺序编码制**：按正文首次引用文献的先后顺序连续编号 [1]、[2]、[3]…；
2. 文后参考文献表按该编号顺序排列，每条只出现一次；
3. 正文引用与文后条目必须一一对应：无漏引、多引、跳号、重复编号；
4. 文后不得出现正文未引用的文献；
5. 草稿中的旧编号不得直接沿用，必须建立"草稿原编号—文献台账—新编号"映射后重新编号。

## 2. 正文引用标注

1. 引用标记置于引用内容处，统一设为**右上标**；
2. 同一处引用多篇：
   - 连续编号：[1-3]；
   - 非连续编号：[1,3] 或 [1][3]，全文写法统一；
3. 标记随标点位置规范：一般置于所引观点/数据之后、标点之前；
4. 无文献支撑的表述标注 [待确认]，不得伪造引用。

## 3. 文后参考文献著录格式

### 3.1 期刊论文 [J]

```
[序号]作者.题名[J].刊名,年,卷(期):起止页码.DOI.
```

示例：

```
[1]翟振武,陈佳鞠,李龙.2015～2100年中国人口与老龄化变动趋势[J].人口研究,2017,41(4):60-71.
[2]陶涛,刘雯莉.独生子女与非独生子女家庭老年人养老意愿及其影响因素研究[J].人口学刊,2019,41(4):72-83.DOI:10.16405/j.cnki.1004-129X.2019.04.006.
```

### 3.2 学位论文 [D]

```
[序号]作者.题名[D].城市:学位授予单位,年份.DOI.
```

示例：

```
[3]亓璐璐.基于WiFi技术的远程养老看护系统设计[D].东北电力大学,2022.DOI:10.27008/d.cnki.gdbdc.2022.000336.
```

> 题录未给出城市时，按题录原样仅著录学位授予单位，不自行补造城市。

## 4. 著录要素细则

1. **作者**：
   - 作者 ≤3 人全部列出；
   - 作者 >3 人保留前 3 人后加"等"；
   - 作者姓名按题录原样著录，不缩写、不改写；
2. **文献类型标识**：期刊 [J]、学位论文 [D]，不得遗漏；
3. **刊名与年卷期页**：刊名完整，年、卷(期)、起止页码齐全；
4. **DOI**：有 DOI 必须保留，前缀 `DOI:`；无 DOI 不补造；
5. **标点**：全文统一，使用规定的点号（. , :）；
6. **段落**：条目悬挂缩进，使用专用样式，字号以模板为准。

## 5. 常见错误

| 错误 | 正确做法 |
|---|---|
| 所有文献都标 [1] | 按首次引用顺序连续编号 |
| 参考文献表为空 | 先建台账，再按编号填充 |
| 编号跨章复用、张冠李戴 | 弃用旧编号，建立映射后重排 |
| 漏写 [J]/[D] | 按文献类型补全标识 |
| 4 位以上作者全列 | 列前 3 人加"等" |
| 正文引用但文后无条目 | 补条目，或删除该引用 |
| 文有条目但正文未引用 | 补引用，或删除该条目 |
| 编造 DOI 或数据 | 以 PDF 原文为准，缺失则不著录 |

## 6. 关于可跳转交叉引用

1. 顺序编码制下文后文献表为纯文本条目，本身没有可被交叉引用捕获的编号；
2. 若为每个编号加书签并把正文标记替换为 REF 域，一旦增删文献极易出现"错误!未找到引用源"；
3. **默认采用右上标文本**（中文毕业论文通行做法），并在格式检查报告中说明；
4. 如作者明确要求可跳转，再按"书签 + REF 域"方式实现；图/表/公式编号则应使用 SEQ + REF 交叉引用。
