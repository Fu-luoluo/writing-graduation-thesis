本文件是综述类毕业论文排版的格式基线。学校官方模板的参数优先于本文件；本文件同时给出无模板时的通用兜底值。

## 1. 模板优先原则

1. 学校/学院提供官方 Word 模板时，以模板样式值为最高依据，不得自行另立标准；
2. 模板缺失时，按以下顺序处理：
   - 用浏览器进入学校教务处/学院官网官方下载页获取（需登录则交回用户操作，来源链接需用户确认）；
   - 仍无法获取时，启用第 6 节通用兜底参数，并在格式检查报告中注明"未套用官方模板"；
3. 不得直接采用搜索引擎中"核心毕业论文网站"等第三方来源的模板，其版本可能过时或张冠李戴；错误模板比无模板更糟。

## 2. 套用方式：样式值覆盖

采用"**样式值覆盖**"，而非整体替换文档：

1. 解析模板的页面设置、分节、样式、字体、字号、行距、缩进、编号等参数；
2. 将这些参数逐项应用到成稿文档对应的节与样式上；
3. 成稿已有的正文内容、引用编号保持不变；
4. 模板中存在而成稿缺失的样式（如"摘要正文""参考文献""图表注""目录"），按模板值创建并应用；
5. 禁止用格式刷或手工格式替代样式；
6. 套用全过程写入格式检查报告，使用"模板值—修改前—修改后"三列对照表。

## 3. 编号依赖检查

套用前必须检查模板的编号定义：

1. 解包模板 `word/numbering.xml`，检查是否存在 `numStyleLink` 等外部样式链接依赖；
2. 若存在依赖（如某 numId 依赖 numStyleLink），**不可直接搬用该 numbering.xml**，否则编号会失效；
3. 处置：保留成稿中已可用的多级编号定义（如原 numId），仅覆盖样式外观（字体、字号、对齐、间距）；
4. 检查结果与处置方式写入报告。

## 4. 页面与分节

1. 纸张 A4（21.0 × 29.7 cm）；
2. 页边距以模板为准；
3. 毕业论文采用多节结构：
   - **前置节**：题名、摘要、关键词、目录，页码使用大写罗马数字（Ⅰ、Ⅱ…）；
   - **正文节**：引言至结论、参考文献，页码使用阿拉伯数字并从 1 重新起算；
4. 分节通过节属性（sectPr）与页码类型（pgNumType）设置，禁止手工排版。

## 5. 各部分格式

### 5.1 标题

1. 使用 Word"标题 1/标题 2/标题 3"样式，多级自动编号，不手动输入编号、不手动加粗；
2. 标题中文字体须显式指定（通常黑体），防止主题字体回退导致渲染为宋体；
3. 一级标题按模板启用"段前分页"（每章另起页）；
4. "参考文献"标题使用标题样式但**取消自动编号**（numId=0），确保更新目录后该条目仍在目录中。

### 5.2 正文

1. 中文宋体、英文 Times New Roman，小四；
2. 行距、段前段后以模板为准；
3. 首行缩进 2 字符，使用 firstLineChars，禁止空格模拟；
4. 两端对齐。

### 5.3 摘要与关键词

1. 摘要 250—300 字；摘要正文字体以模板为准（部分模板用仿宋_GB2312）；
2. 关键词 3—5 个，分号分隔；
3. "摘要：""关键词："标识按模板设置。

### 5.4 目录

1. 使用自动目录域（TOC），禁止手工目录；
2. 目录条目使用专用样式；
3. 域标记 dirty，保证打开时提示更新；提交前更新域，页码与正文一致。

### 5.5 图表

1. 图题在图下、表题在表上，题注样式居中、无首行缩进；
2. 编号使用 SEQ 域自动编号，正文先引用后出现；
3. 表格为三线表，无竖线、无内部横线；
4. 图表不跨页；架构图/流程图使用矢量工具绘制。

### 5.6 参考文献

1. 条目使用专用样式与悬挂缩进，标点统一；
2. 字号以模板为准（常为五号）；
3. 著录规则见 `gbt7714.md`。

### 5.7 页眉页脚

1. 页码使用 PAGE 域；
2. 页眉简洁，可使用 STYLEREF 域显示章节名；奇偶页/首页差异以模板为准。

## 6. 无模板时的通用兜底参数

| 项目 | 参数值 |
|---|---|
| 纸张 | A4 |
| 页边距 | 上下 2.54 cm，左右 3.17 cm |
| 正文 | 中文宋体、英文 Times New Roman，小四（12 pt） |
| 行距 | 1.5 倍 |
| 首行缩进 | 2 字符 |
| 对齐 | 两端对齐，段前段后 0 |
| 标题 | 标题 1/2/3 样式 + 多级自动编号，中文黑体 |
| 页码 | PAGE 域，居中 |
| 页眉 | 简洁题名，宋体五号居中 |
| 参考文献 | 悬挂缩进，GB/T 7714—2015 |
