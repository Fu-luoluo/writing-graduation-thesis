## 1. 内容与结构

- [ ] 结构完整：摘要、关键词、引言、技术演进、研究现状、专题进展、挑战、趋势、结论、参考文献；
- [ ] 无提纲标签式写法残留；
- [ ] 无口语化、宣传化表达；术语全文统一；
- [ ] 摘要 250—300 字；关键词 3—5 个、分号分隔；
- [ ] 章节分工明确，无跨章重复；
- [ ] 挑战与趋势与前文问题一一呼应；
- [ ] 无超长段落，段落长度分布合理。

## 2. 引用与文献

- [ ] 顺序编码、连续递增，无漏引、多引、跳号、重复；
- [ ] 正文引用与文后条目一一对应；
- [ ] 文后无正文未引用条目，正文无文后缺失引用；
- [ ] 著录符合 GB/T 7714—2015：[J]/[D] 标识、作者"等"、年卷期页码、DOI 齐全；
- [ ] 正文引用标记为右上标；
- [ ] 无 PDF 文献仅按主题引用，且已在台账与报告中标注。

## 3. 排版与工程

- [ ] 纸张 A4，页边距符合模板；
- [ ] 分节正确：前置罗马页码、正文阿拉伯从 1 起；
- [ ] 标题全部使用标题样式 + 多级自动编号；
- [ ] "参考文献"标题为标题样式、不编号，且在目录中可见；
- [ ] 正文字体、字号、行距、首行缩进、对齐符合模板；
- [ ] 标题中文显式黑体，无主题字体回退；
- [ ] 自动目录为 TOC 域并已标记 dirty；
- [ ] 图题在下、表题在上，SEQ 自动编号，REF 交叉引用有效；
- [ ] 表格为三线表，无竖线、无内部横线；
- [ ] 图表不跨页，正文先引用后出现；
- [ ] 无空格/回车模拟缩进、居中、页码、目录。

## 4. 真实性核查

- [ ] 关键数据点抽检全部命中文献原文；
- [ ] 无编造文献、编造数据、编造结论；
- [ ] DOI 经 PDF 原文核验，补录项有依据；
- [ ] 无 [待确认] 遗留（或已在报告中逐条列出）。

## 5. 交付物与人工确认

- [ ] 终稿 docx 已交付；
- [ ] 格式检查报告、文献台账已交付；
- [ ] 原文件已备份，未覆盖用户原始文件；
- [ ] 已提示用户打开 Word 后 Ctrl+A → F9 更新域；
- [ ] 已提示检查表格列宽、替换封面占位符；
- [ ] 报告中已注明模板来源与未核验项。
